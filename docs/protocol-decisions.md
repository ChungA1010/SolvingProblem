# v0.4.0 명세와 실제 데이터의 조정 사항

이 파일은 원본 명세서를 수정하지 않고 이번 학습 구현에서 채택한 규칙과 근거를 기록합니다.

| 항목 | 명세의 가정 | 이번 구현과 근거 |
|---|---|---|
| 최종 표본 키 | file + wafer + stage; 한 정답이 한 파일에 존재 | wafer + stage. 실제로 25개 표본이 두 파일에 나뉘어 있어 파일을 키에 넣으면 2,006개 기록과 1,981개 정답이 충돌합니다. 파일 출처는 별도 보존합니다. |
| 파일 간 연결 | 자동 병합 금지 | 장비 ID가 같고 파일별 시간 범위가 겹치지 않는지 검사한 뒤 기록을 모읍니다. 검사 실패 시 중단합니다. 동일 웨이퍼가 재가공된 것인지 완벽히 식별할 추가 메타데이터는 없습니다. 긴 공백은 별도 표시하며 연속 공정이라고 단정하지 않습니다. |
| 분할 단위 | file_id | 같은 웨이퍼가 공유하는 파일들의 연결 성분. A·B Stage까지 포함해 웨이퍼와 파일 양쪽의 누수를 막습니다. 실제 54개 그룹입니다. |
| AUC | 전체 시계열 사다리꼴 적분 | 60 source timestamp units 초과 공백은 적분에서 제외합니다. 임의 보간으로 미관측 구간을 만들지 않습니다. 임계값은 타깃·Test 성능에 맞춰 튜닝하지 않습니다. |
| 중복 | 동일 시각 처리 | 정확한 중복 측정행 제거 후, 동일 시각 센서는 평균, 상태는 출처/행번호 안정 정렬의 마지막 값입니다. 원본 파일은 유지합니다. |
| 물리 모델 | Preston-inspired 관계 | Train의 양수 중앙값으로 개별 채널을 정규화한 압력·회전·슬러리·사용량 경험식입니다. 실제 물성 계수나 인과적 제어 모델로 해석하지 않습니다. |
| 물리+잔차 | y - physics | Train 내부 5-fold 그룹 OOF 물리 예측으로 잔차 타깃을 생성합니다. 최종 물리 모델은 전체 Train으로 적합합니다. |
| 보정 | Stage별 표본 n≥80, 목표 90% | n 조건과 잔차 순위를 구현하고 Test에서 coverage/폭을 보고합니다. 그룹 상관 때문에 이론적 90% 보장을 주장하지 않습니다. |
| 릴리스 | UI·안전·성능 게이트 포함 | 이번 작업은 오프라인 모델 비교이며 전체 서비스 승인·배포는 범위 밖입니다. |

각 후보는 같은 분할과 특징을 사용합니다. 선형/거리 모델에는 Train 기반 표준화를 적용하고, 트리 모델에는 같은 특징의 비표준화 값을 줍니다. 식별자와 절대 시각은 모델 입력에서 제외합니다. 이 조정은 과거 명세의 가정을 실제 데이터에 맞게 명시적으로 해석한 것으로, 원본 PDF 내용의 승인 상태를 변경하지 않습니다.

## 평가 원칙

1. 정답 수치에 접근하지 않는 분할 배치를 먼저 고정합니다.
2. 작은 고정 탐색 범위에서 Validation MAE로 후보를 고릅니다.
3. 선택·설정·모델 해시를 저장한 뒤에 Test를 한 번 엽니다.
4. 모든 후보의 Test 점수를 기록해도 그 점수로 우승 모델을 다시 정하지 않습니다.
5. 이상치 제외 표는 미리 정한 네 웨이퍼에 대한 별도 진단입니다. 주 평가와 모든 학습에는 그대로 포함합니다.
