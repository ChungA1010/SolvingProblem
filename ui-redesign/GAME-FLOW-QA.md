# CMP Factory 주문 검증

검사한 버전은 factory-v5다. 별도 로컬 주소에서 주문을 직접 진행했다. 모바일은 브라우저의 390×844 화면으로 검사했다.

| 시나리오 | 확인한 결과 |
| --- | --- |
| 첫 주문 실습 | 첫 장 121초, 138.58 nm. 측정 후 예상 시간 131초를 직접 적용했다. 다음 장은 148.9 nm였고 오차가 −7.62%에서 −0.74%로 바뀌었다. |
| 검사와 고객 반응 | 6장 모두 규격 충족, 별 3개. 측정 1회 비용 5 P를 제외한 595 P가 공방에 적립됐다. 고객 대화, 추가 목표 판정, 후속 주문이 표시됐다. |
| 조건별 해설 | 동일한 조건·131초로 가공한 W2와 W6의 148.9 nm와 140.7 nm가 기록과 일치했다. 검사 후 실제 측정·정비·자동 정지 횟수가 표시됐다. |
| 종점 감지기 I | 첫 납품 수익으로 380 P에 설치했다. 다음 주문에서 처음에는 시간 연마로 진행했다. W1 측정 후 2장 보정, W2는 180초 설정에서 127.4초에 자동 정지했다. |
| 보정 상태 | Wafer 회전 100%에서 110%로 바꾸자 보정 대기가 표시됐다. 원래 조건에서 W3 직전 보정 잔여 1장은 새로고침 후에도 같았다. W3는 124.8초에 멈췄고 W4 준비 시 보정 만료가 표시됐다. |
| 행동 한도 | 정비로 두 번째 행동을 쓰자 재측정이 필요한 이유와 시간 연마 안내가 표시됐다. 남은 세 장을 가공하고 최종 검사할 수 있었다. |
| 재생과 보존 | WebGL 장비의 이송·연마·측정과 건너뛰기를 실행했다. 이전 규칙 v1~v4, 장비 구매 내역, 검사 공개 상태, 납품 기록·비교의 복원은 자동 검사에 포함했다. |
| 반응형 버튼 | 데스크톱 1280×720과 모바일 390×844에서 실행 버튼이 하단에 보였다. 모바일에서는 시간 입력과 실행 버튼이 첫 화면에 들어왔고 가로 스크롤이 생기지 않았다. 압력 347.893 입력 시 경고와 버튼 잠금, 유효값 복구 후 재실행을 확인했다. |
| CSV | 검사 화면에서 파일을 내려받아 6행을 읽었다. 기존 열 순서를 유지하고 뒤에 보정 관련 3열을 추가했다. W2/W3의 실제 시간 127.4/124.8초, 자동 정지 여부와 보정 사유가 화면과 일치했다. |

자동 검사 167개 통과. 미측정·최대 시간 전략은 센서 두 단계 모두 5개 주문에서 규격 충족 0장이었다. 측정 2회와 유효 기간을 활용하는 전략은 두 단계 모두 5개 주문의 다음 주문 해제 기준(규격 3장 이상)을 충족했다. 테스트한 브라우저 흐름에서 콘솔 오류는 관찰되지 않았다.
