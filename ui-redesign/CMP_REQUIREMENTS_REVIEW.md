# CMP 요구사항 점검 — 로컬 모델 연결 후

검토일: 2026-11-02. **전체 충족으로 판정하지 않는다.** 상태 기반 MRR 예측의
웹 연결은 완료했지만, 소모품/측정 주기 운영 과제, 교육용 변수 수 제한,
독립 검증과 단위 기반 물리 출력에는 미완료 항목이 있다.

## 검토 범위

1. 사용자가 제공한 2026-10-31 'CMP 시뮬레이터 개발 방향 회의자료' 이미지:
   전문가용/교육용 구분, 변수 근거와 상태·소모품, 교육용 핵심 변수 2~3개,
   미션·재도전, 교육 규칙과 실측 검증 결과 구분.
2. [초기 START_HERE](../../START_HERE.md): 공정·장비 운영 교육 목표.
   단, 과거 연속 pressure slider/권장 시간 약속은 이후 승인된 audit 정책을 우선한다.
3. [Issue #2 protocol](../../PHM/docs/mrr_model_protocol.md),
   [Issue #3 policy](../../PHM/docs/pressure_hybrid_policy.md): 예측 시점,
   N=0, feature availability, numerical pressure correction, 단위 정책.
4. 이 웹사이트 README와 ui-redesign의 실제 코드/테스트.

별도 최종 상세계획서·평가표·사용자 테스트 합격 기준은 제공된 자료에서 확인하지
못했다. 이 표는 위 범위의 구현/근거 검토이며 모든 CMP 교육 요구의 인증이 아니다.

## 확인한 실행 결과

- 웹 자동 테스트: 기존 96개와 MRR 연결 클라이언트 6개, **102 passed**.
- 모델 자동 테스트: **18 passed**(모델 저장소에서 이전 단계에 확인; 이번에는 모델 코드 변경 없음).
- 실제 서버 연결 검사 `tools/verify_mrr_connection.mjs`:
  합성 A456 이력 [72,74,73,75] → prev=75, EWMA=73.728,
  API MRR=74.17030873891675. 지정 모델 파일을 직접 계산한 값과 일치.
- 미래 완료시각·pressure 센서 추가 입력은 API에서 거부.
- 웹 origin http://127.0.0.1:8510 CORS, pressure correction 비활성, 시간 null 확인.
- 브라우저: 합성 이력 출처 표시와 모델 버전 확인, 미래 완료시각 오류,
  이력값 75→76 수정 시 낡은 결과 숨김 및 새 MRR 74.7712 확인.
- 반응형: 1280px 및 390px 확인. 좁은 화면에서 이력 표 내부만 가로 스크롤.
- 연결 실패 시 교육 수식으로 fallback하지 않는 동작은 클라이언트 자동 테스트로 확인.

위 시연 입력은 합성 데이터다. 이 결과를 신규 PHM 검증이나 성능 개선이라고
보고하지 않는다. 모델은 고정된 Ridge alpha=1.0, EWMA alpha=0.4 그대로다.

## 우선 남은 결정

1. 교육용 조작을 2~3개로 확정하고 수업 규칙의 근거·가정·미션 목표를 합의한다.
2. 전문가용 최소 범위를 '상태 기반 MRR 예측'으로 승인할지, 소모품 교체와
   측정 주기 운영 과제를 필수로 남길지 결정한다. 필수라면 별도 데이터/구현이 필요하다.
3. 교육용 환산시간과 실제 권장시간의 명칭/설명을 분리 유지한다. 물리 단위가
   확인되기 전 Ridge의 시간 숫자를 켜지 않는다.
4. 모델 API 공개 호스팅과 실제 측정 이력 저장 방법을 정하고, 신규 독립 데이터 및
   학생 사용성 평가를 준비한다. 기존 fold 5를 독립 test로 다시 사용하지 않는다.
