# 8대 공정 실험실 (실험 브랜치 `exp/eight-process-lab`)

`dist/process-lab.html`은 반도체 8대 공정을 **웨이퍼 한 장으로 이어서** 지나가 보는 화면이다. 홈 화면 위쪽의 `8대 공정 실험실` 탭이 연다. 사이트의 중심은 여전히 CMP(팩토리 게임과 학습 실험실)이고, 이 화면은 실험이다.

## 화면

- **공정 줄.** 위쪽에 여덟 공정이 순서대로 놓여 있다. 각 칸의 작은 그림은 그 공정을 지난 뒤의 웨이퍼다(단면, EDS는 웨이퍼 맵, 패키징은 패키지 단면).
- **아무 공정에서나 시작.** 공정을 누르면 그 공정에 들어오는 웨이퍼가 보이고, `여기서 시작`을 누르면 그 공정부터 패키징까지 이어진다. 앞의 공정들은 표준 조건으로 끝낸 것으로 친다.
- **같은 웨이퍼.** 한 공정의 결과가 그대로 다음 공정의 입력이 된다. 직접 기른 산화막 두께가 포토와 식각의 단면에 그대로 나오고, 너무 두꺼우면 식각에서 창이 뚫리지 않아 EDS에서 칩이 모두 불량이 된다.
- **장비가 있는 공정**은 3D 장비를 직접 조작한다. 지금은 산화 하나다.
- **장비가 아직 없는 공정**은 표준 조건으로 지나간다. 화면에는 처리 전후의 단면과 결과 한 줄이 나오고, 그 수치가 가정한 값이라는 것을 밝힌다.
- **공정 기록.** 패키징까지 가면 여덟 공정이 웨이퍼에 남긴 것을 표로 보여 준다.

## 만드는 것

여덟 공정을 한 번씩만 지나서 만들 수 있는 작은 시험 칩이다. p형 웨이퍼에 산화막을 기르고, 산화막에 창을 내고, 창으로 이온을 넣어 n+ 접합을 만들고, 창을 금속으로 채워 평탄하게 간다. 실제 소자는 포토·식각·증착을 수십 번 되풀이하지만, 여기서는 8대 공정이라는 분류를 한 줄로 따라가도록 줄였다.

| 공정 | 웨이퍼에 남기는 것 | 지금 상태 |
|---|---|---|
| 1 웨이퍼 제조 | p형 (100) 300 mm 웨이퍼 | 표준 조건 |
| 2 산화 | 산화막 (목표 500 ± 25 nm) | **장비 있음** |
| 3 포토 | 감광막과 창 무늬 | 표준 조건 |
| 4 식각 | 산화막의 창 | 표준 조건 |
| 5 증착·이온주입 | n+ 접합, 창 안의 장벽막 | 표준 조건 |
| 6 금속배선 | 창을 채운 금속, 평탄화 | 표준 조건 |
| 7 EDS | 칩마다의 양품·불량 | 표준 조건 |
| 8 패키징 | 패키지에 넣은 칩 | 표준 조건 |

CMP는 8대 공정에 따로 이름이 없다(금속배선의 평탄화 등에 들어간다). 지금의 CMP 학습 실험실은 이 줄에 아직 연결하지 않았다.

### 표준 조건의 값 (가정)

`dist/process-lab/flow-model.js`의 `STANDARD`에 있다. 줄을 끝까지 이어 주기 위한 대표값이고 모델로 계산한 값이 아니다. 해당 공정의 장비를 만들면 그 공정의 값은 계산으로 바뀐다.

| 값 | 가정 |
|---|---|
| 웨이퍼 | p형 (100), 300 mm, 10 Ω·cm |
| 산화막 | 500 nm |
| 감광막 두께, 창 너비, 창 간격 | 1,000 nm, 1,000 nm, 3,000 nm |
| 식각이 뚫는 산화막 두께 | 600 nm (500 nm에 과식각 20%). 이보다 두꺼우면 창이 열리지 않는다 |
| 산화막 대 실리콘 식각 선택비 | 20 : 1 |
| 접합 깊이, 장벽막 두께 | 300 nm, 30 nm |
| 칩 크기, 가장자리 제외 | 20 mm, 3 mm (칩 148개) |

## 산화 장비

수직 확산로를 앞쪽을 열어 그린 것이다. 보트에 실린 웨이퍼 25장을 튜브로 올리고, 온도를 올리고, 가스를 골라 산화막을 기른 뒤 식혀서 꺼내 두께를 잰다. 화면은 다음에 할 수 있는 조작만 알려 주고 온도, 시간, 가스는 정해 주지 않는다.

| 부품 | 조작 | 바뀌는 값 |
|---|---|---|
| 보트 | 위로 끌면 튜브에 넣고 아래로 끌면 꺼낸다. 튜브가 800 °C보다 뜨거우면 잠긴다 | 위치 |
| 온도 조절기 | 좌우로 끌기, 휠 | 설정 온도 600~1200 °C (5 °C 단위) |
| N₂ 밸브 | 누르기 | 반응하지 않는 가스. 산화 가스와 함께 열면 분압이 반으로 준다 |
| O₂ 밸브 | 누르기 | 건식 산화 |
| H₂O 밸브 | 누르기 | 습식 산화 |

정보만 보여 주는 부품: 공정 튜브, 히터, 장비 화면, 신호등, 배기. 웨이퍼 모니터의 두께는 계산값이고(실제 확산로에는 공정 중 두께 표시가 없다), 꺼내서 식힌 뒤 잰 값이 공정 기록에 남는다. 웨이퍼 색은 CMP 학습 실험실과 같은 박막 간섭색 계산이다.

### 계산과 출처

`dist/process-lab/oxidation-model.js`. 화면과 무관하고 Node에서 테스트한다.

| 조건 | 식 | 상수의 출처 |
|---|---|---|
| 습식 (H₂O) | Deal–Grove: x² + A·x = B·(t + τ) | Plummer, Deal, Griffin (2000)의 Arrhenius 상수. (100) 실리콘에서는 B/A가 (111)의 1/1.68 |
| 건식 (O₂), 1000 °C 이하 | Massoud: 같은 식에 시간에 따라 줄어드는 가속 항 두 개 | Massoud와 Plummer (1987)의 (100) 상수. 800~1000 °C에서 맞춘 값 |
| 건식 (O₂), 1000 °C 위 | Deal–Grove 상수에 Massoud의 가속 항(외삽) | 위 두 출처 |
| 가스 분압 | B와 B/A는 분압에 비례. 건식의 B/A는 분압의 0.75제곱 | Hollauer (2007) 식 2.28~2.31 |

상수는 모두 C. Hollauer의 학위논문 *Modeling of Thermal Oxidation and Stress Effects* (TU Wien, 2007) [2.6절](https://iue.tuwien.ac.at/phd/hollauer/node16.html)과 [2.7절](https://iue.tuwien.ac.at/phd/hollauer/node17.html)의 표에서 옮겼고, 습식·건식 Deal–Grove 상수는 [위키백과의 Deal–Grove 표](https://en.wikipedia.org/wiki/Deal%E2%80%93Grove_model)와도 맞춰 봤다.

알고 써야 하는 것:

- **출처의 표기와 다르게 쓴 곳이 한 군데 있다.** 학위논문은 Massoud 식의 시간 상수를 τ = τ₀·exp(−E/kT)로 적었다. 그 표의 값을 그대로 넣으면 900 °C에서 τ가 10⁻¹¹분이 되어 가속 항이 없는 것과 같아진다. τ = τ₀·exp(+E/kT)로 읽으면 3.5분과 32분이 되고, 900 °C 건식 1시간에 약 20 nm가 나온다. 그래서 + 부호로 썼다. 원 논문(J. Appl. Phys. 62, 3416, 1987)으로 확인해야 한다.
- 학위논문에는 1000 °C 위의 Massoud 상수도 있다. 1100 °C까지 가져가면 Deal–Grove보다 산화막이 4분의 1쯤 두껍게 나와서 쓰지 않았다. 1000 °C 위에서는 1200 °C까지 맞춘 Deal–Grove 상수를 쓴다.
- 건식 산화는 800 °C 아래에서 외삽이다. 가속 항이 분압에 비례한다는 것은 가정이다.
- 산화 가스가 둘 다 열려 있으면 수증기만으로 계산한다.
- 테스트는 **코드가 출처의 식과 상수를 그대로 따르는지**를 본다. 식 자체가 실측과 얼마나 맞는지는 출처가 밝힌 범위다.

장비의 값은 대표값이고 특정 장비의 값이 아니다: 대기 700 °C, 승온 10 °C/분, 강온 3 °C/분, 보트 이동 6분, 웨이퍼가 주변 온도를 따라가는 시간 상수 3분, 보트 잠금 800 °C, 계측 가능 온도 80 °C. 보트 안의 위치나 웨이퍼 안의 위치에 따른 두께 차이는 아직 없다.

## 파일

| 파일 | 내용 |
|---|---|
| `dist/process-lab.html`, `dist/process-lab/process-lab.css`, `dist/process-lab/app.js` | 화면: 공정 줄, 단면 그림, 공정 기록, 산화 장비의 계기와 안내 |
| `dist/process-lab/flow-model.js` | 여덟 공정, 웨이퍼 상태, 표준 조건, 시작 위치 |
| `dist/process-lab/oxidation-model.js` | 산화 계산과 확산로 |
| `src/process-lab-scene.js` | 3D 공통부: 조명, 바닥, 부품 집기, 끌기, 시점 |
| `src/process-lab/furnace.js` | 수직 확산로 |
| `dist/process-lab/scene.js`, `scene.build.json` | 위 두 파일을 묶은 번들과 그 기록 (`node tools/build-scenes.mjs process-lab`) |
| `tests/process-lab-oxidation.test.cjs`, `tests/process-lab-flow.test.cjs` | 계산 테스트 |

상단 줄, 계기, 부품 카드의 모양은 CMP 학습 실험실의 `dist/lab-3d/lab-3d.css`를 같이 쓴다.

### 다음 공정에 장비를 붙이려면

1. 계산을 `dist/process-lab/<공정>-model.js`로 만들고 테스트를 쓴다. 상수마다 출처를 적는다.
2. 장비를 `src/process-lab/<장비>.js`로 만들고 `src/process-lab-scene.js`의 `EQUIPMENT`에 올린다. 부품은 `kit.control`(조작)과 `kit.info`(정보)로 등록한다.
3. `flow-model.js`에서 그 공정에 `equipment: true`를 붙이고, `apply`가 조작한 결과를 받도록 한다.
4. `app.js`에 그 장비의 부품 카드, 안내, 계기를 넣는다. 지금은 산화 장비의 것이 `app.js` 안에 그대로 있다. 두 번째 장비를 만들 때 장비별로 나눈다.
5. `node tools/build-scenes.mjs process-lab` → 단위 테스트 → `node tools/check-browser.mjs process-lab`.

## 확인하는 것

- `node --test tests/process-lab-oxidation.test.cjs`: 습식·건식 상수와 닫힌 식, 얇은 건식 막의 가속, 두 상수 묶음이 만나는 온도에서의 연속성, 확산로가 일정 온도에서 닫힌 식과 같은 값을 내는지, 질소·분압·승온·보트 잠금·계측.
- `node --test tests/process-lab-flow.test.cjs`: 공정 순서, 아무 공정에서나 시작, 표준 조건으로 끝까지, 직접 만든 산화막이 다음 공정에 넘어가는 것, 너무 두꺼운 산화막이 EDS 불량으로 이어지는 것.
- `node tools/check-browser.mjs process-lab`: 공정 줄, 중간(포토)에서 시작해 공정 기록까지, 확산로의 부품 카드, 실제 마우스 입력으로 보트 올리기 → 온도 → 밸브 → 성장 → 뜨거울 때 보트 잠금 → 식히기 → 꺼내기 → 계측 → 다음 공정으로 넘기기.

소프트웨어 렌더러에서만 돌려 봤다. 실제 그래픽 카드에서의 속도와 손맛은 사람이 확인해야 한다.

## 아직 없는 것

산화 말고는 장비가 없다. 보트 위치별·웨이퍼 안 두께 차이, 얇은 게이트 산화막을 요구하는 과제, 산화막이 너무 얇을 때의 뒤 공정 영향(이온주입 마스크), 실제와 같은 EDS 측정값과 수율 분포, CMP 학습 실험실과의 연결, 터치 화면, 어두운 화면 색.
