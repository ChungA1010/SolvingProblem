# CMP 연마 장비 시뮬레이터 (Issue #6)

`dist/lab-sim.html`은 PHM 2016 데이터로 학습한 상태 추적 모델 위에서 동작하는 CMP 연마 장비 운영 시뮬레이터다. 학생은 3D 장비를 보며 예측을 읽고, 연마 시간·압력·정비·계측을 결정하고, 결과를 확인한다.

## 두 가지 모드

| 모드 | 결과를 정하는 것 | 바꿀 수 있는 것 |
|---|---|---|
| **연습** (가상 장비) | 학습된 모델을 앞으로 돌린 가상 장비. 결과는 **모델이 만든 값**이다 | 연마 시간, 주 압력(관측 범위), 계측 정책, (자유 연습) 레시피·패드 교체·장비 휴지 |
| **실전 검증** (실제 기록) | PHM 2016 fold 5의 **실측값**(14일, 327장) | 연마 시간, 계측 정책 |

### 과제

- **하루 운전 · 5개 챕터** (연습, 40장, 추천): 한 번의 운전 안에서 상황이 바뀐다. 챕터가 바뀔 때 안내 카드가 뜬다.

  | 챕터 | 웨이퍼 | 상황 | 계측 | 압력 |
  |---|---|---|---|---|
  | 1 기본 운전 | 1~8 | 정상 | 매 장·즉시 | 잠김 |
  | 2 재가동 | 9~13 | 3시간 휴지 후 재가동 | 매 장·즉시 | 잠김 |
  | 3 패드 교체 | 14~18 | 패드 교체 직후 | 매 장·즉시 | 잠김 |
  | 4 계측 지연 | 19~30 | 결과가 2장 늦게 도착 | 매 장·2장 지연 | 잠김 |
  | 5 압력 이상 | 31~40 | 33·36·38번째에 연마 중 주 압력 −6.5% | 매 장·즉시 | 조절 가능 |

  통과 기준은 40장 중 26장 이상 규격(목표 ±5%)이다. 결과 창에서 챕터별 수율·오차·예측 구간 폭을 보여준다.
- **자유 연습** (연습, 60장): 레시피, 압력, 정비, 계측 정책을 직접 정한다.
- **실제 기록 재생** (실전): 연습한 운영이 실제 데이터에서도 통하는지 확인한다.

가상 장비는 seed가 같으면 같은 웨이퍼 흐름을 만든다. 결과 창의 "같은 웨이퍼 흐름으로 다시"를 누르면 판단만 바꿔 결과를 비교할 수 있다.

## 실행

재생 데이터(`dist/lab-sim/data/replay.json`)는 데이터 공개 범위가 결정될 때까지 저장소에 넣지 않는다. 연습 모드도 연마 중 센서 모양을 이 파일의 실제 기록에서 가져온다. 처음 한 번 로컬에서 만든다.

```powershell
python -m tools.lab_sim.build_lab_data --wafer-table <preprocessed_audit_source/preprocessed/wafer_table.csv> --traces <Dataset/CMP1/CMP-data/training>
cd ui-redesign
npm run preview   # http://127.0.0.1:8510/lab-sim.html
```

## 모델과 가상 장비

**상태 추적 모델 v2**(예측): 레시피별 칼만 필터가 "정상 압력 기준 제거 속도"를 추적한다.

- 투입 전: 압력 설정값으로 예측 MRR과 90% 구간을 낸다.
- 연마 중: 관측 압력으로 (p/p_ref)^α 보정을 한다. A456은 α=1(Preston), B456은 α=0(반응 근거 없음)이다.
- 측정 대기: 측정되지 않은 웨이퍼는 상태를 바꾸지 않는다.
- 실측 갱신: 휴지·패드 교체 뒤 첫 장은 일회성으로 보정한다.

개발 fold 평가에서 투입 전 정확도는 Ridge v1과 통계적으로 같았다. 자세한 내용은 [평가 보고서](../runs/lab_sim_state_model_v2/REPORT.md)에 있다.

**가상 장비**(연습 모드의 결과): 같은 학습값을 앞으로 돌린다.

```
상태     = μ + φ(이전 상태 − μ) + N(0, q)
결과 MRR = 상태 × (압력/기준)^α + 첫 장 보정 + 패드 마모 + N(0, r)
```

- 예측 모델은 숨은 상태를 보지 못하고 측정값만 받는다.
- fold 1~4로 정하고, 학습 밖 fold 5와 같은 사건 흐름으로 150번 만들어 비교했다. 25개 통계 중 24개가 실제 값과 맞았다. 예측 오차는 실제 2.917 vs 가상 2.895였다. 자세한 내용은 [검증 보고서](../runs/lab_sim_virtual_tool/REPORT.md)에 있다.
- 3D와 게이지는 실제 fold 5 센서 기록을 틀로 쓰고, 설정 압력과 이상 상황에 맞춰 크기를 조정한다.

## 화면

- **위:** 4단계 안내(연마 시간 정하기 → 연마 진행 → 계측 결정 → 결과 확인), "지금 할 일" 문구, 과제·챕터 배지
- **가운데:** 팀 3D 연마부(`cmp-scene.js` 등, 수정하지 않음). 센서 값으로 접근·접촉·분리, 회전, 패드 압축, 슬러리를 구동한다. 압력 경보 배너와 예상 누적 제거량을 함께 보여준다.
- **오른쪽 메뉴:**
  - [운전] 공정 조건(압력·레시피·정비) → 연마 시간 → 시작 / 연마 중 종료 시간 조정 / 계측 결정
  - [계측 설정]
  - [과제 안내] 챕터 목록, 조작 방법, "다루는 것 / 다루지 않는 것"
- **아래 결과:** 실시간 공정 데이터, 예측 상세, 장비 상태·알람, 관리도, 운전 기록, 결과 창(챕터별 성적)

## 다루지 않는 것 (데이터 근거 없음)

웨이퍼 안 균일도와 구역 압력, 막 두께·종점·디싱·이로전, 회전·슬러리·온도 효과, 결함·세정, 물리 단위(값은 원시 단위)는 다루지 않는다. 화면의 개념 카드에서 그렇게 밝힌다.

## 검증

```powershell
node --test tests/lab-sim-*.test.cjs
```

- 상태 모델·가상 장비 Python–JS 일치(1e-9), 재생 엔진, 연습 엔진 테스트가 있다. 연습 엔진 테스트는 챕터·정책·사건·압력 잠금·이상·seed 재현·자유 연습 조작을 다룬다.
- 테스트는 합성 데이터만 쓴다.
- 헤드리스 Edge로 하루 운전 전체(챕터 안내 5개, 압력 이상 경보와 시간 조정, 챕터별 결과 창)와 자유 연습 압력·정비 조작을 확인했다. 콘솔 오류는 없었다.
- 기능 동작 확인이며 교육 효과나 독립 예측 성능 검증은 아니다.
