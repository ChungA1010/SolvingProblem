# CMP 연마 장비 시뮬레이터 (Issue #6)

`dist/lab-sim.html`은 PHM 2016 데이터로 학습한 상태 추적 모델 위에서 동작하는 CMP 연마 장비 운영 시뮬레이터다. 학생은 참고 정보를 보고 레시피·압력·회전 속도·정비·연마 시간·계측을 직접 정하고, 3D 장비로 연마한 뒤 결과를 확인한다. **모델은 정답(권장 시간)을 미리 채워 주지 않는다.**

배울 것: 장비 상태는 보이지 않게 계속 변한다 → 같은 시간으로는 결과가 흔들린다 → 계측 결과로 다음 웨이퍼 시간을 고친다(R2R) → 계측을 줄이면 비용은 줄지만 수율이 떨어진다.

## 하나의 시뮬레이터

과제 선택은 없다. 페이지를 열면 바로 가상 장비로 운전이 시작되고, 정해진 끝 없이 계속 이어진다(최대 999장).

| 결과 기준 (설정 탭) | 결과를 정하는 것 | 바꿀 수 있는 것 |
|---|---|---|
| **가상 장비** (기본) | 학습된 모델을 앞으로 돌린 가상 장비. 결과는 **모델이 만든 값**이다 | 연마 시간, 주 압력(관측 범위), 회전 속도(80~120%, 교과서 가정), 레시피(바꾸면 유지), 패드 교체·장비 휴지, 계측 |
| **실제 기록** | PHM 2016 fold 5의 **실측값**(14일, 327장) | 연마 시간, 계측. 압력·회전 속도·레시피·정비는 기록된 그대로 잠긴다 |

결과 기준을 바꾸면 새 운전이 시작되고, 지금 운전은 비교 기록(브라우저 localStorage)에 저장된다.

### 운전 중 결정

- **참고 정보 (읽기만):** 목표 제거량과 규격(±5%), 기준 레시피(시간·MRR·압력), 같은 레시피의 최근 계측 결과(당시 시간·속도·압력 조건 포함), 결과를 모르는 채 연마한 장 수, 계측 대기, 모델 추정 MRR과 90% 범위. "제거량 = MRR × 연마 시간"만 알려 준다.
- **내가 정하는 값:** 레시피, 주 압력, 회전 속도, 정비, 본 연마 시간. 조작마다 근거 배지가 붙는다(데이터 근거 / 데이터: 반응 없음 / 교과서 가정). 연마 시간은 처음에 비어 있고, 이후에는 같은 레시피에 **내가 지난번에 쓴 값**만 남긴다. 권장 시간·규격 확률은 보여 주지 않는다.
- **연마 중:** 주 압력이 설정에서 1.5% 넘게 벗어나면 경보가 뜬다. 무엇이 일어나는지(A456: Preston 식대로 덜 깎임, B456: 기록상 반응 없음)와 모델의 연마 중 추정을 보여 주고, 학생이 종료 시간을 직접 다시 입력한다.
- **연마 후:** 웨이퍼마다 **계측 의뢰 / 계측 생략**을 직접 고른다. 계측하지 않은 웨이퍼는 상태 추정을 바꾸지 않으므로 다음 추정 범위가 넓어진다.
- **자동 운전 (모델이 시간 결정):** 재생 바의 스위치. 비교용이다.

### 설정 탭

- **돌발 상황** (켜기/끄기): 가상 장비에서 웨이퍼마다 seed에 따라 휴지 3시간(5%), 패드 교체(5%), 연마 중 주 압력 −6.5% 저하(8%, 본 연마 8초 뒤부터)가 생긴다. 휴지·교체는 투입 전에 안내 배너로 알린다.
- **계측 규칙:** 직접 결정 / 매 장 / 2·5·10장마다. 자동 운전에서 "직접 결정"이면 매 장 계측한다.
- **결과 도착:** 즉시 / 1~5장 뒤. 결과가 들어와야 상태 추정이 갱신된다.
- **새로 시작 / 같은 흐름으로 다시:** 가상 장비는 seed가 같으면 같은 웨이퍼 흐름(숨은 상태와 돌발 상황)을 만든다. 같은 흐름으로 다시 하면 판단만 바꿔 결과를 비교할 수 있다.

### 도움말 탭: 추천 연습

순서 없이 해 보면 자동으로 체크된다.

1. 참고 정보를 보고 직접 정한 연마 시간으로 계측 결과를 규격(±5%) 안에 넣기
2. 주 압력을 바꿔 모델 추정 MRR이 달라지는 것 보기 (A456)
3. 회전 속도를 바꿔 보기 (Preston 식, 교과서 가정)
4. 계측을 몇 장 건너뛰고 모델 추정 범위가 넓어지는 것 보기
5. 결과 도착을 늦춰 놓고 운전해 보기
6. 휴지·패드 교체 직후 첫 장을 연마해 보기
7. 연마 중 압력 경보에 종료 시간을 직접 고쳐 대응하기
8. 결과 기준을 실제 기록으로 바꿔 실측값으로 운영해 보기

### 결과 보기

위쪽 **결과 보기** 버튼으로 언제든 연다(실제 기록은 327장이 끝나면 자동으로 열린다).

- 요약: 규격 수율, 계측 횟수, 평균 제거량 오차, 모델 추정 범위(90%) 적중률과 폭, 시간 조정 횟수
- **같은 웨이퍼를 다른 방식으로 운전했다면:** 매번 기준 레시피 시간(보정 없음) / 내 운전 / 모델 자동 보정 + 내 계측 선택 그대로 / 모델 자동 보정 + 매 장 계측. 웨이퍼의 실제 MRR은 연마 시간과 무관하므로, 다른 방식은 시간만 바꿔 같은 웨이퍼에 다시 적용한다(`session.compare()`). 차이를 문장으로 요약하고, 20장 미만이면 우연의 영향이 크다고 알린다.
- **상황별 결과:** 정상 / 휴지·교체 직후 / 측정 미반영(stale) / 압력 경보 / 압력 변경 / 회전 속도 변경. 한 웨이퍼가 여러 상황에 속할 수 있다.
- 추천 연습 진행, 이전 운전과 비교, 계측하지 않은 웨이퍼의 실제 결과
- 버튼: 운전 계속 / 새로 시작 / 같은 흐름으로 다시 / 실제 기록↔가상 장비 전환

## 모델과 가상 장비

**상태 추적 모델 v2**(예측): 레시피별 칼만 필터가 "정상 압력 기준 제거 속도"를 추적한다.

- 투입 전: 압력 설정값으로 예측 MRR과 90% 구간을 낸다.
- 연마 중: 관측 압력으로 (p/p_ref)^α 보정을 한다. A456은 α=1(Preston), B456은 α=0(반응 근거 없음)이다.
- 측정 대기: 측정되지 않은 웨이퍼는 상태를 바꾸지 않는다.
- 실측 갱신: 휴지·패드 교체 뒤 첫 장은 일회성으로 보정한다.

개발 fold 평가에서 투입 전 정확도는 Ridge v1과 통계적으로 같았다. 자세한 내용은 [평가 보고서](../runs/lab_sim_state_model_v2/REPORT.md)에 있다.

**가상 장비**(가상 장비 기준의 결과): 같은 학습값을 앞으로 돌린다.

```
상태     = μ + φ(이전 상태 − μ) + N(0, q)
결과 MRR = [상태 × (압력/기준)^α + 첫 장 보정 + 패드 마모 + N(0, r)] × 회전 속도 비
```

- **압력(α):** A456은 학습 구간에 압력 변화가 적어 Preston 값 α=1을 기본값으로 넣었고, 학습 밖 fold 5에서 압력을 낮춘 A456 21장이 α≈1로 반응한 것을 확인했다. B456은 압력이 높았던 웨이퍼에서 반응이 약해 우도로 α=0을 골랐다. 압력은 기록된 범위 안에서만 바꿀 수 있다.
- **회전 속도 (교과서 가정):** 실제 기록은 레시피마다 속도가 고정이라 데이터로 확인할 수 없다. Preston 식(MRR ∝ 압력 × 속도)을 그대로 적용해 MRR 전체에 속도 비를 곱하고, 예측도 같은 배율을 안다. 계측값은 속도 비로 나눠 상태를 기록된 속도 기준으로 유지한다. 범위는 80~120%다.

- 예측 모델은 숨은 상태를 보지 못하고 측정값만 받는다.
- 숨은 상태의 흐름은 seed로만 정해지고 학생의 판단과 무관하다. 그래서 같은 흐름으로 다시 하면 판단의 차이만 결과에 남는다.
- fold 1~4로 정하고, 학습 밖 fold 5와 같은 사건 흐름으로 150번 만들어 비교했다. 25개 통계 중 24개가 실제 값과 맞았다. 예측 오차는 실제 2.917 vs 가상 2.895였다. 자세한 내용은 [검증 보고서](../runs/lab_sim_virtual_tool/REPORT.md)에 있다.
- 3D와 게이지는 실제 fold 5 센서 기록을 틀로 쓰고, 설정 압력과 이상 상황에 맞춰 크기를 조정한다.

## 화면

- **위:** 4단계 안내(연마 시간 정하기 → 연마 진행 → 계측 결정 → 결과 확인), "지금 할 일" 문구, 결과 기준 배지, 돌발 상황 안내 배너, 결과 보기 버튼
- **가운데:** 팀 3D 연마부(`cmp-scene.js` 등, 수정하지 않음). 센서 값으로 접근·접촉·분리, 회전, 패드 압축, 슬러리를 구동한다. 압력 경보 배너와 예상 누적 제거량을 함께 보여준다.
- **오른쪽 메뉴:**
  - [운전] 참고 정보 → 모델 추정 MRR(참고) → 내가 정하는 값(레시피·압력·회전 속도·정비·연마 시간) → 시작 / 연마 중 종료 시간 직접 입력 / 계측 의뢰·생략
  - [설정] 결과 기준, 돌발 상황, 계측 규칙·결과 도착, 계측 대기열, 새로 시작
  - [도움말] 추천 연습, 조작 방법, "다루는 것 / 다루지 않는 것"
- **아래 결과:** 실시간 공정 데이터, 예측 상세, 장비 상태·알람, 관리도, 운전 기록

## 다루지 않는 것 (데이터 근거 없음)

웨이퍼 안 균일도와 구역 압력, 막 두께·종점·디싱·이로전, 슬러리 성분·유량·온도 효과, 결함·세정, 물리 단위(값은 원시 단위)는 다루지 않는다. 회전 속도는 교과서 가정(Preston)으로만 다룬다. 화면의 도움말에서 그렇게 밝힌다.

## 검증

```powershell
node --test tests/lab-sim-*.test.cjs
```

- 상태 모델·가상 장비 Python–JS 일치(1e-9), 실제 기록 엔진, 가상 장비 엔진 테스트가 있다. 가상 장비 테스트는 끝 없는 운전과 웨이퍼별 계측 결정, seed별 돌발 상황 재현과 끄기, 사건 예고, 같은 seed·같은 판단의 재현, 압력 반응, 레시피 유지·정비, 계측 지연과 상황별 요약을 다룬다.
- 테스트는 합성 데이터만 쓴다.
- 테스트는 회전 속도의 Preston 배율(가상 장비·예측·3D 회전·계측 정규화)과 운전 방식 비교도 확인한다. 모델 권장 시간을 그대로 따르고 매 장 계측한 운전은 비교의 모델 자동 보정 두 줄과 정확히 같아야 한다.
- 헤드리스 Edge로 확인했다. 시작 시 연마 시간은 비어 있고 시작 버튼은 잠겨 있으며 화면 어디에도 권장 시간이 없다. 직접 입력한 24장 운전에서 회전 속도 110%, 압력 경보 중 종료 시간 직접 입력, 계측 의뢰/생략, 결과 창의 운전 방식 비교가 동작했다. 콘솔 오류는 없었다.
- 기능 동작 확인이며 교육 효과나 독립 예측 성능 검증은 아니다.
