# 가상 장비(연습 모드) 검증 — 학습 구간 밖 fold 5와 비교 (Issue #6)

## 목적

연습 모드에서는 사용자가 실제 기록과 다른 조건으로 운전할 수 있어야 한다. 그러려면 결과를 상태 모델이 학습한 값으로 만들어야 한다. 이 보고서는 그렇게 만든 가상 장비가 **실제 장비와 같은 성질의 결과를 내는지** 확인한다.

## 가상 장비

[`tools/lab_sim/virtual_tool.py`](../../tools/lab_sim/virtual_tool.py)

```
장비 상태  level_t = μ + φ(level_{t-1} − μ) + N(0, q)          레시피별, 웨이퍼마다 한 걸음
결과 MRR   mrr_t   = level_t × (p_t / p_ref)^α                  압력 반응 (A456 α=1, B456 α=0)
                   + 휴지·패드 교체 첫 장 보정
                   + 패드 마모 기울기 × (패드 사용량 − 기준)
                   + N(0, r)                                     웨이퍼별 흩어짐
```

- q, r, α, 첫 장 보정은 상태 모델 v2(`state-model-v2.json`, fold 1~4)의 값을 그대로 쓴다.
- 예측 모델은 숨은 상태를 보지 못하고 측정값만 받는다. 이는 실제 운전자와 같은 조건이다.
- 패드 마모 기울기는 fold 1~4에서 패드 수명 고정효과로 추정했다.
  - A456: −0.20 / 100 사용량
  - B456: −0.49 / 100 사용량
  - 측정 잡음보다 훨씬 작다.
- **평균 회귀(φ, μ)를 넣은 이유:** 첫 검증에서 순수 랜덤 워크는 짧은 거리 성질은 맞았지만 14일 동안 너무 멀리 떠돌았다(A456 sd 실제 3.9 vs 가상 8.2). 그래서 다음 기준으로 φ와 μ를 정했다.
  - φ: fold 1~4의 fold별 분산 **중앙값**에 정상 분산이 맞도록 정했다. 중앙값을 쓰면 운전 수준이 바뀐 fold 1에 끌려가지 않는다.
  - μ: 가장 최근 학습 fold(4)의 평균
  - 결과는 A456 φ=0.900, μ=77.44 / B456 φ=0.943, μ=83.37이다.
  - 예측 모델은 여전히 랜덤 워크를 가정한다. 단순한 R2R 제어기를 쓰는 실제 운전 상황과 같다.

## 방법

fold 5(학습에 쓰지 않음)의 실제 순서·레시피·압력·패드 사용량·휴지·패드 교체를 그대로 둔다. MRR 값만 가상 장비로 150번 다시 만든다. 그다음 실제 fold 5의 통계가 가상 결과의 5~95% 범위에 드는지 본다.

## 해석

- 가상 장비는 실제 fold 5와 같은 수준의 흩어짐, 웨이퍼 간 변화, 연속성을 보인다.
- 사용자가 경험하는 **예측의 어려움**(칼만 오차와 구간 포함률, 측정 지연·드문 측정 때의 오차 증가)도 실제와 같은 수준이다. 연습 모드의 핵심 경험이 실제 데이터와 맞는다는 뜻이다.
- 범위를 벗어난 1개는 경계값이다(3.273 vs 3.281). 25개를 90% 범위로 비교하면 우연히 2~3개가 벗어나는 것이 정상이다.

## 한계

- 이 검증은 실제 기록과 **같은 조건**에서의 성질만 확인한다. 사용자가 압력을 바꾸는 경우는 A456 저압 21장(fold 5)의 Preston α≈1 반응 근거에 기대며, 근거가 제한적이다.
- 허용 압력 범위는 개발 데이터 전체에서 관측된 1~99% 범위다(A456 251.7~270.0, B456 251.4~270.0). 이 범위 밖은 허용하지 않는다.
- 회전, 슬러리, 균일도, 두께·종점은 다루지 않는다.
- 가상 장비의 결과는 모델이 만든 값이며 실측이 아니다. 화면에 그렇게 표시한다.
