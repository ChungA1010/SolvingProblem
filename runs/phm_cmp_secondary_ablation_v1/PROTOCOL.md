# 후속 챔버 특징 제외 비교: 학습 전 계획

2026-09-19. Train 신호 검사에서 다른 웨이퍼 주 연마와 후속 챔버의 동시 기록 일치를 확인했다.
이 결과만으로 입력 제거가 유리하다고 단정할 수 없어 기존 P2와 제한된 비교를 수행한다.

## 고정 비교

- 대조군 `original`: reconstruction v2의 P2 통합 모델. 기존 21개 부모 적합 결과를 해시 확인 후 그대로 재사용한다.
- 후보 `primary_only`: `p2_secondary_`로 시작하는 물리 통계 52개만 제거한다. 125개 입력에서 73개 입력(주 챔버 52개, lag/neighbor 21개)이 남는다.
- 같은 Train 행·순서·seed·20회 내부 wafer CV·하이퍼파라미터·특징 선택 절차·결합 가중식을 사용한다.
- 특징 선택과 모델 계수, CV 오차에 따른 가중치의 **수치**는 새 입력에서 다시 계산한다. 고정 가중치로 단순 예측만 바꾸는 실험이 아니다.
- 사용량 이웃·과거 이력은 그대로다. Persistent/KNN은 각 내부 분할 및 평가에서 기존 예측과 같아야 한다.
- 챔버 간 평균 방식 변경, phase 재선택, 시각 이동, 타깃 수정, 표본 추가 삭제, clipping, Ridge 교체, 새 하이퍼파라미터 탐색은 하지 않는다.

## 데이터와 평가

- 학습은 기존 공식 Train 1,977건(기존 4개 제외 정책 유지)뿐이다. 신호 검사의 1,981건과 구분한다.
- 같은 wafer/file 연결 그룹 바깥 5fold, 같은 시간순 1,551/166/260건(학습/평가/경계 제외)을 유지한다.
- 5바깥+1시간순+1최종 × 3조건 = 21개 후보 적합; 각 적합에서 내부 CV 20회 후 최종 학습을 한다.
- 이력 조건은 원래 P2의 raw usage 이웃과 prior-start lag다. 미래 Train 이웃을 허용하는 논문 비교 조건이며, 완료된 과거 전용 모델과 직접 순위를 비교하지 않는다.
- 내부 CV는 원형과 같은 wafer 기준이다. 파일 그룹의 중첩 수를 기록하고, 바깥 파일 그룹 검증 및 별도 시간순 결과와 구분한다.
- 새 모델과 설정을 봉인한 뒤 공식 Validation/Test 입력을 예측하고 정답을 결합한다. 각 424건이며 이미 여러 번 본 데이터이므로 참고 평가다.
- 두 절차의 통합 성능과 5개 구성 모델을 함께 보고한다. 전체·Stage·condition별 MSE/RMSE/MAE/R²/RE를 같은 표본에서 계산한다.
- Train의 신호 일치 여부별 오차를 보조 분석한다. 검사에서 미확인인 표본을 독립 신호라고 해석하지 않는다. 공식 Validation/Test에는 같은 검사를 새로 시행하지 않는다.
- Test 최저값으로 재튜닝하거나 모델을 자동 교체하지 않는다. 바깥 그룹 및 시간순 중 한쪽이라도 악화되면 일관된 개선으로 부르지 않는다.

## 검증과 보존

- 원래 예측 재현, 새 모델 재로딩, 모든 평가 표본의 저장 예측과 재계산 지표 일치를 확인한다.
- 후보가 secondary 열을 참조하지 않는지, query 정답·순서·secondary 값 변화에 예측이 불변인지 확인한다.
- 내부 420개 분할의 ID 해시·학습 표본·특징 투표·오차·가중치를 다시 확인한다. 최종 가중식과 통합 예측도 직접 재계산한다.
- 기존 모델·논문 baseline·이전 실험 결과는 해시로 보존하고 API/Unity 모델은 유지한다.
- 학습 코드·분할·계획은 실행 전에 봉인한다. 예측·모델·검증·실패를 포함한 결과를 기존 GitHub 브랜치에 게시한다.
