# 논문별 baseline 구축·재평가 기록

2026-09-18에 기존 학습 모델을 논문별 독립 실행기로 재로딩해 검증했다. **13개 모델군·14개 저장 묶음·156개 평가 행**을 확인했다. 원문 미기재 조건을 공개한 부분 재현이며 새로운 독립 Test가 아니다.

| 논문 | 모델 수 | 저장 묶음 수 | 결과 |
|---|---:|---:|---|
| P1: Decision Tree-Based Ensemble Learning | 5 | 4 | [보고서](p1/REPORT.md), [전체 지표](p1/metrics.csv), [20회 반복](p1/repeat_summary.csv) |
| P2: Enhanced Virtual Metrology | 6 | 6 | [보고서](p2/REPORT.md), [전체 지표](p2/metrics.csv) |
| P3: RF/CPP 보정 | 2 | 4 | [보고서](p3/REPORT.md), [전체 지표](p3/metrics.csv) |

각 저장 묶음은 P1의 Stage A/B, P2의 Cond1/2/3, P3의 chamber 456/123 경로에 대응하며 official/grouped 두 분할이 있다. 저장 모델은 기존 경로를 참조한다. 이 결과 폴더만 복사하지 말고 저장소 전체를 복제한다.

[검증 기록](checks.json): 테스트 73개 통과, 모든 논문의 CLI 예측 일치, P3 실제 전체 데이터 재학습 후 24개 지표 재현을 확인했다. P1/P2는 기존 학습 결과를 재활용해 재평가했으며 이번 구성 작업에서 전체를 다시 학습했다고 주장하지 않는다. P1/P2의 새 학습 분기·학습 표본 격리·반복 횟수는 자동 테스트로 확인했다.

저장 모델과 기존 예측의 최대 차이는 P1 `1.75e-10`, P2/P3 `8.53e-14` 이내였다. 이전 연구 실행의 설정·모델·점수는 보존했다. 이 작업은 논문별 baseline 실행 환경을 구성한 것이며 기존 Physics+ML 후보 전체와의 새로운 통합 비교나 배포 모델 교체가 아니다.
