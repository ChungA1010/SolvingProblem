# P2 시간순 내부 선택 실험 v4 — 학습 전 계획

2026-09-19. boosted v3의 그룹 검증 개선이 시간순/공식 Test에 이어지지 않은 관찰에 따른 마지막 후속 개발 비교이다.
논문 baseline은 수정하지 않는다. 이번 실행은 completed 이력 정책만 사용하며, 논문 재현 결과로 표시하지 않는다.
모든 데이터와 이전 Test를 이미 본 상태이므로 새 독립 검증이 아니다.

## 고정 데이터와 비교

이전 Train 1,977건, 바깥 5개 웨이퍼/파일 그룹 분할 및 시간순 1,551/166/경계 제외 260건을 그대로 사용한다.
Cond1/2/3별 학습하며 이전 robust v2, boosted v3와 동일 표본에서 비교한다.
completed 이력은 종료 < 조회 시작 및 다른 웨이퍼의 학습 제거율만 사용하며 종료 즉시 계측을 가정한다.
바깥 그룹 검증의 모델 학습 자체는 미래 학습 표본을 포함할 수 있다. 전체 시간 순서는 별도 시간순 평가로 확인한다.

## 내부 rolling-origin 선택

각 바깥 학습 부분/조건에서 표본 시작 시각의 40/60/80% 분위수를 경계로 정한다. 타깃을 사용하지 않는다.
각 경계보다 **그룹 전체가 종료한** 표본만 학습한다. 검증은 그룹 전체가 그 경계 이후 시작하고 다음 경계 전에
종료한 그룹이다. 마지막 창은 상한이 없다. 경계를 가로지르는 그룹은 해당 창에서 배제한다.
이전 창의 검증 표본이 이후 창의 학습 표본에 포함되는 것은 완료된 과거 라벨의 이용이며 허용한다.
검증 표본은 창 사이에 중복되지 않는다.

학습 60건/6그룹 미만 또는 검증 10건/2그룹 미만인 창은 결과를 보지 않고 건너뛴다.
유효 창이 2개 미만이면 실패로 중단한다. 현재 표본 수만 사전 점검했고 모든 바깥 부분에 2개 이상 유효 창이 있다.
건너뛴 창, 경계, 실제 fit/query ID를 동결해 공개한다. 평가는 유효 창의 예측을 합친 MSE이며 fold 평균을 단순 평균하지 않는다.

## 후보와 학습

boosted v3와 동일한 base_direct/joint_direct/base_residual/joint_residual 네 후보와 CatBoost 4개 설정을 사용한다.
기본 특징 125개, 결합 특징 401개, 학습용 이력의 그룹 교차 적합, 잔차 기준값, 입력 결측 처리,
예측의 학습 y min/max 제한을 그대로 둔다. CatBoost grid와 구현 소스는 기존 파일을 그대로 참조하고 해시를 보존한다.

기존 robust v2 절차도 각 시간순 학습 창에서 **처음부터 재적합**해 동일 검증 창에서 비교한다.
이 대조군 내부의 그룹 CV·가중 결합 규칙은 기존 그대로이며 그 전체 절차의 미래 창 예측을 평가한다.
각 후보의 CatBoost 설정과 최종 후보를 시간순 검증 MSE 최소로 선택하고 동점은 ID 사전순이다.
따라서 바뀌는 것은 최상위 선택용 검증 방식이며 학습용 이력의 교차 적합은 v3와 같다.

바깥 5개+시간순 1개+전체 최종 1개 × 3조건 = 21개 조건 적합이다. 유효 창 개수는 사전 동결 계획에 기록한다.
각 창마다 CatBoost 16개와 robust v2 절차 1개, 각 조건 적합의 마지막에는 선택된 설정의 CatBoost 4개를 재적합한다.
바깥/최종 기존 robust v2 대조군은 같은 학습 부분의 저장 모델을 해시 확인 후 재사용한다.
3개 CPU worker, CatBoost/RF당 4개 thread. 새 코드·입력·분할·계획을 학습 전에 동결한다.

## 평가와 종료

최종 설정을 고정한 뒤 기존 Validation/Test 각 424건을 참고 평가하고 지표를 독립 재계산한다.
Test에서 다른 후보가 좋아도 재선정하지 않는다. 양호/불리한 결과 모두 보존한다.
기존 API/Unity 모델을 바꾸지 않고 이번 범위의 추가 탐색을 마친 뒤, 세 논문의 원문 발표 지표와 재현 v2 결과를 최종 비교한다.
신규 시간순 실험은 논문별 재현 모델과 구분해 별도 표에 기록한다.

```powershell
python -m cmp_ml.temporal_experiment prepare
python -m cmp_ml.temporal_experiment train
python -m cmp_ml.temporal_experiment evaluate
python tools/verify_temporal.py
```

기존 boosted v3 입력 캐시와 robust v2 모델 체크포인트가 필요하다.
새 실행은 `--run-dir runs/my_temporal_run`으로 만들며 완료된 실행은 덮어쓰지 않는다.
